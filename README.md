## ✨ Features

<div align="center">

| 🔐 Feature | 📋 Description |
|:---|:---|
| 🎣 **Phishing Simulation** | Realistic fake login pages, spoofed emails & social engineering traps |
| 🧩 **Scenario-Based Training** | Multi-step attack chains mimicking real-world threat actors |
| 🎮 **Interactive Learning** | Decision trees where your choices determine the outcome |
| 🧠 **Awareness Modules** | Bite-sized cybersecurity lessons with actionable takeaways |
| 📊 **User Progress Tracking** | Score, performance metrics & learning milestones |
| 🌙 **Modern Android UI** | Material 3 design with smooth animations and intuitive UX |
| 🔔 **Simulated Threat Alerts** | Realistic push notifications that mirror real attack vectors |
| 🏆 **Achievement System** | Gamified rewards to keep users engaged and motivated |

</div>

<br/>

### 🎣 Phishing Simulation Engine
Simulate end-to-end phishing attack scenarios including:
- **Email Phishing** — Spoofed sender addresses, urgency-driven copy, malicious link overlays
- **SMS Phishing (Smishing)** — Fake delivery notifications, OTP harvesting simulations
- **Social Media Phishing** — Fake login portals mimicking popular platforms
- **Voice Phishing (Vishing)** — Script-driven social engineering conversations

### 🧩 Scenario-Based Learning
Users navigate branching storylines where each decision reveals security consequences:
- **Beginner** — Spot obvious red flags in low-pressure scenarios
- **Intermediate** — Multi-vector attacks with time pressure
- **Advanced** — APT-style simulation with chained attack stages

### 📊 Analytics & Progress
- Per-scenario scoring with rubric-based feedback
- Weakness identification & personalized improvement tips
- Session history with timeline view

## 🚀 Installation

### 🛠️ Build from Source (Developers)

**Prerequisites**

| Tool | Version |
|---|---|
| Android Studio | Hedgehog or later |
| JDK | 17+ |
| Android SDK | API 24+ (minSdk) |
| Gradle | 8.x |

**Steps**

```bash
# 1. Clone the repository
git clone https://github.com/Harshal350/CyberSim.git

# 2. Navigate into the project
cd CyberSim

# 3. Open in Android Studio
#    File → Open → Select the cloned folder

# 4. Sync Gradle dependencies
#    Click "Sync Now" when prompted

# 5. Run on emulator or physical device
#    Run → Run 'app'   (Shift + F10)
```

### 📱 Install via APK (End Users)

1. Download the latest `.apk` from the [**Releases**](https://github.com/Harshal350/CyberSim/releases/latest) section
2. On your Android device, navigate to:
   `Settings → Security → Unknown Sources → Enable`
3. Open the downloaded `.apk` file
4. Tap **Install** and wait for completion
5. Launch **CyberSim** from your app drawer

> ⚠️ *Enabling Unknown Sources is only required for sideloading. Always download APKs from trusted sources.*
